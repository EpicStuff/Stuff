# Stuff
misc. projects that don't deserve their own repo.

## clamav
point VirusEvent to binary in clamav config and it will send notification to all users on a virus event with option to delete or quarantine the file, or ignore the path

## frp.taml
converts a taml/yaml config to toml for frp, reorganizes config layout and adds default config options feature. see example.taml for frpc example 

## koharu.fish
lets you process a koharu project with 2 extra features, 1. unload models before translate for when low gpu ram, and 2. optional export to cbz

## list chromium extension name
goes through all the folders with extension ids and gives u their name

## vaultwarden-nohttps
patch the website to allow http
