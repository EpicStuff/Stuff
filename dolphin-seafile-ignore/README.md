# Dolphin Seafile Ignore

A native KDE Dolphin file item action plugin that shows **Add to Seafile ignore** only for files and folders inside local Seafile libraries.

It discovers Seafile library worktrees from Seafile's own `repo.db`, then appends relative paths to that library's `seafile-ignore.txt`.

## Install on Arch / EndeavourOS

From this directory:

```sh
makepkg -si
```

Then close every Dolphin window and open Dolphin again.

If `makepkg` says a base build tool is missing, install the standard Arch build group first:

```sh
sudo pacman -S --needed base-devel
```

## Behaviour

- The action is hidden outside Seafile libraries.
- The action is hidden for the library root itself.
- Multiple selected items are supported, including selections from different Seafile libraries.
- Files are added as paths such as `notes/file.txt`.
- Folders are added with a trailing slash such as `build/`.
- Existing identical entries are not duplicated.
- If `### SEAFILE-SYMLINK (AUTOGENERATED) ###` is present after a blank line, new entries are inserted before that blank line so the autogenerated section remains separated.
- Writes use `QSaveFile`, so the ignore file is replaced atomically.
- Seafile's current client code watches `seafile-ignore.txt`, so no Seafile restart should be required.

Seafile ignore syntax treats `*` and `?` as wildcards, lines beginning with `#` as comments, and trims surrounding whitespace. To avoid accidentally creating a broader pattern than the selected filename, the action is hidden for a selected relative path that cannot be represented exactly under those rules.

## Seafile data directory discovery

The plugin checks `CCNET_CONF_DIR` first. If it is set, it looks for `seafile.ini` inside that directory.

It then falls back to:

```text
~/.ccnet/seafile.ini
```

For additional or nonstandard Seafile configurations, create:

```text
~/.config/dolphin-seafile-ignore.conf
```

with:

```ini
[General]
SeafileIniFiles=/path/to/another/seafile.ini
```

Qt `QStringList` syntax can be used if more than one path is needed.

## Uninstall

```sh
sudo pacman -R dolphin-seafile-ignore
```

## Important Seafile limitation

Adding a path to `seafile-ignore.txt` does not remove an already synced copy from the server. It prevents subsequent local changes from being synced according to Seafile's ignore behaviour.
